# Netflix-Content-Analytics-Dashboard
This project analyzes content available on Netflix to uncover trends in movies and TV shows over time.
The goal is to transform messy raw data into meaningful insights that help understand:

Content growth trends

Popular genres

Country-wise production

Differences between movies and TV shows

The project solves the problem of unstructured and inconsistent data, turning it into a clean, interactive dashboard that supports data-driven decisions.

3. Proposed Features

Content Growth Analysis (Yearly trends of titles added)

Movies vs TV Shows Comparison

Top Producing Countries Visualization

Genre Distribution Analysis

Duration Analysis (Short, Medium, Long content)

Interactive Filters (Year, Genre, Country)

Dynamic Dashboard for user exploration

4. SQL, Excel and Tableau Concepts You Plan to Use
🔹 SQL

Data cleaning (handling NULL values, removing duplicates)

Date formatting and extraction (YEAR, MONTH)

Creating new columns using CASE statements

Aggregations (COUNT, GROUP BY)

🔹 Excel

Removing blank cells and handling missing data

Data formatting and structuring

Creating calculated columns (categories, durations)

Basic data validation and preparation

🔹 Tableau

Creating interactive dashboards

Line charts (time trends)

Bar charts and pie charts

Filters and parameters

Data storytelling using visuals
