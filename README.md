# Netflix-Content-Analytics-Dashboard
This project analyzes content available on Netflix to uncover trends in movies and TV shows over time.

The goal is to transform messy raw data into meaningful insights that help understand:

Content growth trends
Popular genres
Country-wise production
Differences between movies and TV shows

     - Problem Statement
This project aims to analyze Netflix’s content library to uncover trends in content growth, genre distribution, country-wise production, and audience targeting. By transforming raw and unstructured data into a clean and interactive dashboard using Excel, the project provides insights that support data-driven decision-making in content strategy and platform development.

Primary Audience:
1. Business analysts & decision-makers at streaming platforms
2. Content strategists - who decide what content to produce
-Understand what content performs well
-Identify growth opportunities
-Support data-driven content decisions


Research Questions
1. How has Netflix content grown over time?
     - Number of titles added per year

2. What is the distribution between Movies and TV Shows?
     - Which type dominates
      - Whether trends are changing

3. Which countries produce the most Netflix content?
    - Top contributing countries
    - Global distribution
      
4. What are the most popular genres?
   - Most frequent genres
   - Audience preferences


3. Proposed Features
- Content Growth Analysis (Yearly trends of titles added)
- Movies vs TV Shows Comparison
- Top Producing Countries Visualization
- Genre Distribution Analysis
- Duration Analysis (Short, Medium, Long content)
- Interactive Filters (Year, Genre, Country)
- Dynamic Dashboard for user exploration

5. Tools and Libraries
Microsoft Excel (for data preparation)
Dataset source: Kaggle (Netflix dataset)
